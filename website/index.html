Cursor keeps one shared settings folder. Every extension, every login, every AI chat, mixed across every project you open it for. Prism gives each context its own --user-data-dir — and its own title bar color, so Cmd+Tab actually tells you something.

What it does

⌘

Real isolation

Each profile is its own --user-data-dir — separate extensions, settings, logins, and chat history. Nothing bleeds between clients.

◑

Color-coded windows

Every profile gets its own title bar color, merged straight into settings.json.

{
  "window.titleBarStyle": "custom"
}
★

Your real Cursor, protected

Your existing install shows up as a pinned, un-deletable "Main Cursor" profile — clone it to start a new one from your current setup.

⇲

Drag, drop, launch

Drop a project folder onto a profile card to open it there directly — or double-click to launch with its default folder.

●

Live running status

A dot shows which profiles are actually open right now, with a one-click quit for each.

↺

Delete means Trash

Removing a profile sends it to the Trash / Recycle Bin — never an irreversible rm -rf.

How it works

01

Create a profile

Name it, pick an emoji and a color. Takes about five seconds.

02

Prism launches Cursor scoped to it

A dedicated data directory, invisible to every other profile.

--user-data-dir ~/.cursor_profiles/work
03

The window colors itself

That profile's accent becomes its title bar — recognizable in Mission Control before you even read the label.
